# GigSchool Project Rules

## Project Overview
- GigSchool is a closed student freelance marketplace for MIT ACSC college
- Only students with `@mitacsc.edu.in` email can sign up
- Support email: sahillamture511@gmail.com

## Tech Stack
- **Backend**: Python, FastAPI, Supabase (database + auth + storage)
- **Frontend**: React, TypeScript, Vite, TanStack Query, Zustand
- **AI**: OpenRouter API with Google Gemini 2.5 Flash
- **Styling**: Tailwind CSS with dark mode support
